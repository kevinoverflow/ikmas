# Scripts

This directory contains ad hoc demos, diagnostics, and migration-era utilities. These files are not part of the primary pytest suite and are not required to start the app.

Run scripts from the repository root, for example:

```bash
python scripts/debug_ingestion.py path/to/file.pdf
python scripts/artifact_generation_demo.py
```

Root-level shell entry points stay at the repository root:

- `run.sh`
- `run_tests.sh`
